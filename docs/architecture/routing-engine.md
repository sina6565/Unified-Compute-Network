# موتور مسیریابی
مراحل هدف: اعتبارسنجی capability، فیلتر Providerهای غیرفعال/ناسازگار، رعایت انتخاب صریح کاربر، ارزیابی health/latency/قیمت، انتخاب طبق policy شفاف، fallback فقط به Provider مجاز و ثبت دلیل انتخاب. Fallback نباید بی‌اطلاع کاربر به سرویس پولی یا modality متفاوت منتقل شود. Router اجرایی هنوز پیاده‌سازی نشده است.
