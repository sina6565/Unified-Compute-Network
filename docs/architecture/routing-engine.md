# موتور مسیریابی

فرآیند پیشنهادی: classify task → filter capability/terms → health/quota/SLA → verify price freshness → enforce budget → rank by effective cost and quality → execute → meter. Fallback باید محدود و قابل مشاهده باشد. Retry هزینه دارد؛ cache و compression نیز باید از نظر کیفیت پایش شوند.
