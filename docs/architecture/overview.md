# نمای کلی معماری

اجزا: gateway، provider registry، adapters، router، metering، billing و pools. Gateway هویت مشتری را بررسی می‌کند؛ credential upstream در adapter جدا می‌ماند. Router capability، health، capacity، قیمت معتبر، SLA و budget را می‌سنجد. ظرفیت‌ها به دلیل modality، مدل، زمان، region، latency و کیفیت کاملاً fungible نیستند.
