# طراحی AMM و ظرفیت

فرمول `x·y=k` برای دارایی‌های قابل‌تعویض مناسب است؛ ظرفیت محاسباتی زمان‌مند و task-specific است. مدل congestion قابل آزمایش: `P_i = P_base_i × (1 + α_i × (1 − h_i)^β_i)`. پارامترها باید با داده واقعی کالیبره شوند. provider ناسالم، فاقد ظرفیت یا خارج از SLA از candidate set حذف می‌شود.
