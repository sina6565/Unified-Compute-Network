# پرسش‌های متداول

**آیا UCN رمزارز است؟** خیر؛ MVP اعتبار داخلی و ledger دارد.

**آیا LP سود تضمینی دارد؟** خیر؛ بازار LP فعال نیست و APY تضمین نمی‌شود.

**آیا providerها قابل بازفروش‌اند؟** فقط در صورت مجاز بودن طبق شرایط رسمی و قرارداد.

**آیا ارزان‌ترین مدل همیشه انتخاب می‌شود؟** خیر؛ ابتدا capability، quality، health، SLA و budget بررسی می‌شود.
